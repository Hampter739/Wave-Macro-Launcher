# Wave-Macro-Launcher
This is a macro launcher for a variety of games, most are free to use, offer cool QOL features and gui. This tool is with passion and not with a goal of monetary gain.

It uses the discord auth to identify per user, make accounts, the laucher, rest of the eco system has a chat like feature similar to discord.

We are considering adding own name changing, profile picture changing incase games or mods start banning people from games because of the use of our tools

The macros are EXTERNALS. What that means they go into roblox instance memory, read the live tree paths to ui elements, etc to find where they are making them insanely fast and reliable but they are against roblox and many games TOS so use at OWN RISK
